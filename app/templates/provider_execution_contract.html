Provider Execution Contract

The seven independent execution capabilities per provider, derived read-only from the three registries that actually own them (ProviderCapabilities for discovery, ApplicationCapabilities for the headless application adapters, and the browser-assist capability matrix for the real-browser engine). Every “true” names the source of its evidence.

Browser fill capability is not submission capability. A provider can have working form discovery, field mapping, autofill and resume upload and still have submission_supported = false — that is the case for every real ATS here. submission_supported is read from that provider's own ApplicationCapabilities.submission_supported alone and is never inferred from a browser observation. Today only the deterministic in-process mock_ats test fixture sets it.
